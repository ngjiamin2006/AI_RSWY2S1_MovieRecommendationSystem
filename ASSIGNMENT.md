## Topic Options (pick ONE)

### 1. Supervised Machine Learning
- Solve a classification problem (e.g., disease prediction, credit approval).
- Get a public dataset (UCI, Kaggle, OpenML).
- Preprocess: missing values, normalization, feature engineering.
- Each member implements a different classifier (ANN, SVM, KNN, etc.).
- Compare via accuracy, precision, recall, F1.

### 2. Unsupervised Machine Learning
- Solve a clustering problem (e.g., customer segmentation, anomaly detection).
- Preprocess: scaling, encoding, dimensionality reduction.
- Each member implements a different clustering method (K-means, MeanShift, DBSCAN).
- Compare via inertia, silhouette score, etc.

### 3. Recommender System
- Real-life scenario (e-commerce, streaming, library, procurement).
- Each member implements a different approach (collaborative filtering, content-based, hybrid).
- Evaluate via precision/recall/F1, MSE/RMSE, or user satisfaction survey.

### 4. Natural Language Processing
- e.g., sentiment analysis or text classification.
- Must build a **web crawler** to gather data (or use a reliable dataset).
- Preprocess: cleaning, tokenization, stemming/lemmatization, feature extraction (TF-IDF, embeddings).
- Each member implements a different model (Naïve Bayes, SVM, BERT/transformer, Logistic Regression, Decision Tree, deep learning).
- Compare via accuracy, precision, recall, F1.

### 5. Chatbot Development
- Real-life scenario (customer support, FAQ, personal assistant).
- Choose approach: ML-based (train NLP model for intent/response) **or** platform-based (Dialogflow, Pandorabots, Rasa).
- Each member builds a different chatbot implementation.
- Evaluate via F1/precision/recall (intent), BLEU/ROUGE (response generation), usability/satisfaction.

### 6. Image Processing / Computer Vision
- e.g., OCR, object detection, pedestrian/action recognition, face recognition, image segmentation.
- Get dataset (MNIST, PASCAL VOC, CIFAR-10, LFW, etc.).
- Preprocess: resizing, normalization, augmentation, labeling/annotation.
- Each member implements a different algorithm (CNN, classic ML, YOLO, Mask R-CNN, etc.).
- Compare via accuracy, precision, recall.

## Part 1: Documentation (40%)
Sections graded (each scored 0–20, scaled to 40% total):
1. **Introduction** — background, problem statement, objectives, significance, research gap.
2. **Related Work** — describe, evaluate, and compare prior studies; identify gaps.
3. **Methodology** — system flow, dataset description, algorithm(s), evaluation metrics.
4. **Results & Discussion** — present results aligned to objectives; interpret and discuss implications.
5. **Conclusion & References** — achievements, limitations, future work; APA-style references; dataset/tool citations.

Also required: **Appendix A** (Plagiarism Statement, per student), **Appendix B** (AI Disclosure Statement — must disclose any AI tool/prompt usage and how output was verified), **Appendix C** (Free-Rider Report, only if needed).

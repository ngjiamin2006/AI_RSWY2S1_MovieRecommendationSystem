## Entry 1 — 2026-07-21 — Initial project scaffold

**AI tool used:** Claude (Sonnet 5), via Claude Code CLI

**What was generated:**
- `data_loader.py`, `algorithms/content_based.py`, `algorithms/collaborative_filtering.py`,

**Data source:**
- Dataset is **MovieLens `ml-latest-small`**, downloaded directly from the official
  GroupLens Research server (`https://files.grouplens.org/datasets/movielens/ml-latest-small.zip`).
  This is real, publicly published rating data — not synthetic, not self-collected, and not
  generated by the AI. Must be cited in the documentation as:
  > F. Maxwell Harper and Joseph A. Konstan. 2015. The MovieLens Datasets: History and Context.
  > ACM Transactions on Interactive Intelligent Systems (TiiS) 5, 4, Article 19.

**Code origin:**
- All code in the files above was written directly by Claude during this session,
  based on general/standard algorithmic knowledge (cosine similarity for content-based
  filtering, item-based collaborative filtering, weighted-average hybrid combination).
- No external tutorial, blog post, StackOverflow answer, or GitHub repository was
  fetched, browsed, or copied from to produce this code during this session.
- The three algorithms implemented (content-based, collaborative filtering, hybrid)
  correspond to the exact method names the assignment brief itself lists as options —
  they are standard/textbook techniques, not a novel method, which is what the
  assignment expects the team to demonstrate.

**Verification performed:**
- Ran `data_loader.load_data()` and confirmed the dataset loads (9,742 movies, 19 genres).
- Called each algorithm's `recommend(...)` function directly with sample inputs and
  confirmed sensible, non-empty output.
- Ran `evaluation.py` end-to-end on a real train/test split; got real precision@10 /
  recall@10 / F1@10 numbers for all three algorithms and RMSE for collaborative filtering.
- Launched the Streamlit app headlessly and confirmed it serves (HTTP 200) with no
  startup errors.
